╔══════════════════════════════════════════════════════════════════════════╗
║                        INTERACTION FLOW                                  ║
╚══════════════════════════════════════════════════════════════════════════╝

1. User types message in textarea
2. User clicks "Send" or presses Enter
3. Message appears immediately as "You" message
4. "Thinking..." indicator appears under Agent
5. After AI response, "Thinking..." is replaced with actual message
6. Textarea is cleared and ready for next message
7. Chat history persists across page refreshes (via Durable Object)
